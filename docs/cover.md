# Rotorift cover

The cover uses the real Rift X5 model render as reference. The built-in imagegen
tool generated the final marketing image; no CLI/API fallback was used.

- Master: `web/assets/rotorift-x5-cover.png` (1734 × 907).
- Web/OG/README: `web/assets/rotorift-x5-cover.jpg`, JPEG encoding of the same image.
- Available for later portfolio use; no portfolio files have been changed.

Prompt: create a wide orange/charcoal hangar cover, preserving the reference
X5's carbon arms, tri-blade smoked props, orange mounts, action camera, battery,
antenna and green PCB. Keep the game model aesthetic; place the drone on the
right, with generous margins and warm orange lighting/flight arc. Exact text:
“ROTORIFT.”, “FPV. On the go.” and “Lightweight browser simulator”. No competing
brands, extra text or watermarks.
